# Прогресс

Личный трекер комплексного развития: спорт, питание, обучение.

- Работает без сервера и без аккаунтов.
- Данные хранятся только в браузере устройства.
- Стек: чистый HTML, CSS и JavaScript. Зависимостей нет.

## Запуск

**Локально, для разработки:**

```bash
py tools\serve.py
```

Затем открыть `http://localhost:8000/app.html`.

Отличие от `python3 -m http.server` одно: кэширование запрещено. Иначе браузер
подолгу держит старые версии файлов, и правка не доезжает до экрана.

Открывать `index.html` двойным кликом нельзя — ES-модули не работают по протоколу `file://`.

**На телефоне:** опубликованная версия на GitHub Pages, добавленная на главный экран.

## Структура

Полная карта файлов — в `docs/files.md`. Коротко:

```
index.html    проверка контура        app.html      приложение
check.html    самопроверка ядра       states-*.html витрины для согласования
assets/css/   стили, начиная с tokens.css
src/core/     данные: схема, хранилище, миграции, копии
src/modules/  темы: пока только вода
src/ui/       интерфейс: кружок, карточка, графики, жесты, панели
docs/         модель данных, контракты, маршрут к серверу, журнал решений
```

Зависимости идут только вниз: `ui` не читает хранилище, `core` не знает про воду,
темы не знают друг о друге. Если ради новой темы приходится править `ui` или
`core` — значит контракт составлен неверно.

## Данные

Личные данные в репозиторий не коммитятся. Резервная копия — экспорт JSON из самого приложения.
