# Прогресс

Личный трекер комплексного развития: спорт, питание, обучение.

- Работает без сервера и без аккаунтов.
- Данные хранятся только в браузере устройства.
- Стек: чистый HTML, CSS и JavaScript. Зависимостей нет.

## Запуск

**Локально, для разработки:**

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`.

Открывать `index.html` двойным кликом нельзя — ES-модули не работают по протоколу `file://`.

**На телефоне:** опубликованная версия на GitHub Pages, добавленная на главный экран.

## Структура

```
index.html              стартовая страница
manifest.webmanifest    описание для установки на главный экран
assets/css/tokens.css   цвета, шрифты, отступы — единый источник
assets/css/base.css     сброс и базовая типографика
assets/icons/           иконки приложения
src/core/               хранилище, модель данных, события
src/ui/                 переиспользуемые элементы интерфейса
src/modules/            прикладные модули: вода, спорт, питание, обучение
docs/                   карта модулей и журнал решений
CLAUDE.md               регламент работы над проектом
```

## Данные

Личные данные в репозиторий не коммитятся. Резервная копия — экспорт JSON из самого приложения.
