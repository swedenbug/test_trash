# Handoff: экран «Сегодня»

## Обзор
Главный экран личного приложения дисциплины (репозиторий swedenbug/test_trash): список ждущих тем с действиями в одно касание, блок выполненного с прогрессом дня, цели со сроками и наградные состояния (хром/золото). Утверждён пользователем в дизайн-сессии 7 сентября 2026.

## О файлах дизайна
`Сегодня.dc.html` - **дизайн-референс на HTML**, прототип вида и поведения, не производственный код. Задача - воспроизвести его в целевом окружении репозитория: статические HTML/CSS/JS без сборщика и без внешних зависимостей, слои core/modules/ui по docs/contracts.md. Логика прототипа (класс Component) - справка о поведении, не для копирования.

## Точность
**Hi-fi.** Цвета, размеры, отступы, шрифты и анимации финальные - воспроизводить точно. Все токены совпадают с assets/css/tokens.css репозитория.

## Жёсткие рамки (из брифа)
- Колонка 440px, тёмная тема, системные шрифты, зона касания от 44px.
- Дефис вместо длинного тире во всех текстах. Никаких обнуляемых серий и сравнений.
- Не больше одного тревожного сигнала на экране: красная чёрточка срочности только у самой запущенной темы.

## Экран: структура сверху вниз
1. **Шапка** - sticky, top:0, z-index:40, фон rgba(10,10,11,0.92) + backdrop-blur 12px. Слева дата «7 сентября, понедельник» (14px, #8c949c; формат: число месяц, день недели). Справа кнопка меню 44x44 (две линии 20x2px, #eceff2).
2. **Ждут** - заголовок 16px/600 + счётчик-пилюля (mono 11px, фон #1c1e21). Карточки отсортированы по срочности: hard → soft → done.
3. **Сделано** - заголовок + счётчик; справа фраза дня; под заголовком полоса дня 3px.
4. Волосяная линия во всю ширину: rgba(255,255,255,0.055).
5. **Цели** - заголовок 18px/700, справа значок кредитов (щит + число, #e0a32e, рамка rgba(224,163,46,0.45), радиус 999px). Подзаголовок «АКТИВНЫЕ» (11px, letter-spacing .08em, uppercase, #5b6268). Карточки целей. Затем строка-переключатель «ЗАВЕРШЁННЫЕ · N» (тот же стиль + шеврон, поворот 180° при раскрытии, transition .2s) - список завершённых скрыт по умолчанию.
6. Подсказка о пропуске (12.5px, #8c949c): «Не успеваешь - скажи об этом заранее. Объявленный пропуск тратит запас, срывом не считается.» Кнопка «Сегодня пропускаю» (44px, фон #1c1e21, рамка #2a2d31, радиус 12px). В прототипе не действует - экран пропуска отдельная задача.
7. **Нижние переходы** - в конце потока (margin-top:auto, НЕ fixed), ниже них ничего. Верхняя волосяная линия, padding-bottom: env(safe-area-inset-bottom). 5 кнопок 44x52: главная, сегодня (активная, #eceff2, остальные #8c949c при opacity .55), три заглушки-квадрата.

## Карточка ждущей темы
Контейнер: фон #141517, рамка 1px #2a2d31, радиус 16px, padding 13px (слева 18px), flex, gap 12px.
- **Чёрточка срочности**: absolute слева, 3px x 58% высоты, радиус справа. Цвета: done #303c4a; soft linear-gradient(180deg,#3ce07e,#0e9e6a); hard linear-gradient(180deg,#ff6b4a,#b3121f).
- **Иконка**: блок 42x42, радиус 12px, фон rgba(цвет темы, 0.13); внутри SVG-силуэт 24px в цвете темы, opacity .92 (пути в прототипе, ICONS).
- **Тексты**: название 15px/600; подпись 12.5px #8c949c («500 из 2500 мл»); полоса прогресса 4px, фон rgba(255,255,255,0.10), заливка цветом темы, transition width .5s cubic-bezier(.3,.7,.3,1). У «Настроения» полосы нет.
- **Справа**: кнопка-пилюля min-width 72px, высота 44, фон #1c1e21, рамка #2a2d31, текст 14px/600; ниже время неактивности (mono 11px, #5b6268, nowrap): «2 ч назад», «вчера».
- **Hover/касание**: translateY(-2px), рамка rgba(230,234,238,0.40), тень 0 0 0 1px rgba(230,234,238,0.16), 0 6px 22px rgba(230,234,238,0.07), 0 10px 26px rgba(0,0,0,0.45); transition .18s ease. На кнопке :active scale(0.95).
- **Кофе (тема-ограничение)**: под «+1» текстовая кнопка «на сегодня всё» (12px, #8c949c, подчёркивание rgba(140,148,156,0.4), hover #eceff2).

## Поведение действий
- **+250 / +10 / +1**: значение растёт на шаг (clamp по норме), полоса доезжает, кнопка вспыхивает на 320мс (фон rgba(цвет,0.38), рамка цветом темы), появляется таблетка отмены.
- **Таймер (чтение)**: первый тап - идёт счёт минут, кнопка «Стоп» с рамкой цвета темы; «Стоп» или достижение нормы останавливает. В прототипе 1 мин = 700мс - в продукте реальное время.
- **Достижение нормы** (кроме ограничений): карточка уезжает вниз - opacity→0, translateY(20px) за .4s, затем max-height и margin схлопываются за .45s (задержка .06s); через ~550мс запись появляется в «Сделано» с «выполнено в HH:MM» (настроение - «отмечено в HH:MM», кофе по «на сегодня всё» - «в пределах нормы · HH:MM»). Повторные тапы во время уезда игнорируются (защита от дублей).
- **Таблетка отмены**: fixed по центру колонки, bottom 24px, z-index 60; 44px, радиус 999, фон rgba(28,30,33,0.96) + blur; текст «Отменить +250» и кольцо отсчёта 7с (SVG stroke-dasharray). Тап откатывает состояние целиком (значение + уезд). Стопка отмен - по src/ui/undo.js.

## Блок «Сделано»
- Строка: 44px, иконка темы 20px в её цвете, имя 14px, справа подпись mono 11px #8c949c nowrap; opacity .55, hover opacity .85 + фон #141517, радиус 12px.
- Тап разворачивает в полномасштабную приглушённую карточку (opacity .62): иконка в блоке 42px, имя, подпись, полная полоса в цвете темы, хром-галочка справа. Повторный тап сворачивает.
- **Полоса дня**: доля = выполнено / (выполнено + ждут). Заливка: до 70% - #5b6268; ≥70% - хром linear-gradient(90deg,#7c858d,#eef3f7,#7c858d); 100% - золото linear-gradient(90deg,#e0a32e,#f6d27a,#e0a32e). Фраза справа 12px: «До полного дня - N дел(а)» (#8c949c), при 100% «День выполнен целиком» (#e0a32e). Ограничения (кофе) участвуют в счёте дня.

## Карточка цели
Фон: radial-gradient(130% 130% at 0% 0%, rgba(цвет темы,0.13), прозрачный 58%) поверх #141517; рамка #2a2d31, радиус 16px, overflow hidden.
- Заголовок 15px/600, тема 12.5px #8c949c, полоса 5px в цвете темы, слева «День 24 из 90» (12px #8c949c).
- Справа внизу кружок «+» (26px видимый, hit 44px, фон #1c1e21, рамка #2a2d31) - раскрывает блок: описание цели (12.5px) и «Пропусков в запасе: 7 из 9» (12px; #e0a32e если запас на исходе, иначе #8c949c). «+» меняется на «−».
- **≥70% срока**: хромовая угловая лента (полоска 110x7px, rotate 45°, top 14px right -32px, gradient хром, свечение rgba(230,234,238,0.35)), рамка rgba(230,234,238,0.30).
- **≥90%**: то же золотом - gradient(#e0a32e,#f6d27a,#e0a32e), свечение rgba(224,163,46,0.5), рамка rgba(224,163,46,0.45).
- **Завершённая**: золотая корона 17px в правом верхнем углу с двойным drop-shadow (0 0 6px rgba(224,163,46,0.65) + 0 0 14px rgba(224,163,46,0.30)); фон с золотым тинтом rgba(224,163,46,0.10); hover - рамка rgba(224,163,46,0.75) и тень 0 0 0 1px rgba(224,163,46,0.35), 0 6px 24px rgba(224,163,46,0.14); в деталях вместо запаса - «+5 кредитов доверия» (#e0a32e).

## Состояние
- values по темам, список выполненного за день (с подписью и временем), развёрнутость строк «Сделано», раскрытость деталей целей, показ завершённых целей, стопка отмен (7с на запись), состояние таймера чтения.
- Уезд карточки: флаг leaving → через 550мс перенос в done. Отмена восстанавливает снимок состояния до действия.

## Токены (= tokens.css репозитория)
Фоны: #0a0a0b / #141517 / #1c1e21; линии #2a2d31, волосяная rgba(255,255,255,0.055). Текст: #eceff2 / #8c949c / #5b6268. Роли: красный #d8323c, хром #e6eaee, сигнал #e0a32e, опасность #ff5a4a, мягкое напоминание #35bf6b. Цвета тем демо: вода #58b6ee, отжимания #3ce07e, чтение #a78bfa, кофе #e0a32e, настроение #f472b6. Шрифты: --f-body системный, --f-num моноширинный, --f-geo Avenir Next/Futura. Радиусы 8/14/22 (карточки экрана - 16), касание 44px.

## Ассеты
Иконки тем - рукописные SVG-пути (одним path, viewBox 0 0 100 100) в прототипе: капля (из src/ui/circle.js), гантель, книга, чашка, сердце, галочка, таблетка, корона, щит кредитов, шеврон. Внешних ассетов нет.
