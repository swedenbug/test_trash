# ТЗ: шеринг результата (главный экран)

Для: Claude-разработчик, репозиторий swedenbug/test_trash.
Дизайн-референс: `Главный.dc.html` (оверлей шеринга) + handoff-README.md, раздел «Шеринг». Утверждено в дизайн-сессии 7 сентября 2026.

## Суть
Пользователь делится результатом темы картинкой: сохраняет в фото телефона или отправляет в мессенджер. Точка входа - пятый пункт «Поделиться» в меню ⋯ карточки (после четырёх ползунков, отделён волосяной линией `#2a2d31`, иконка share 15px + подпись 13px `#eceff2`). Есть у всех подключённых тем; у неподключённых меню ⋯ нет.

## Ограничения репозитория
- Статические HTML/CSS/JS, без сборщика и внешних зависимостей.
- Слои по docs/contracts.md: ui не лезет в store напрямую, данные приходят из модуля темы.
- Токены только из assets/css/tokens.css. Дефис вместо тире во всех строках. Касания от 44px.

## Поток
1. Тап «Поделиться» → полноэкранный оверлей предпросмотра. Фон `rgba(10,10,11,0.88)` + `backdrop-filter: blur(14px)`. Меню ⋯ закрывается.
2. Шапка оверлея: слева «Поделиться» (15px `#eceff2`), справа кнопка ✕ 44x44.
3. Под шапкой сегменты «Карточка / Кадр 9:16» (стиль сегментов 7д/30д: высота 30, радиус 15; активный - рамка `#e6eaee`, текст `#eceff2`). По умолчанию - «Кадр 9:16».
4. По центру предпросмотр (см. ниже). Под предпросмотром таблетки-указатели вида - те же, что на карточке (активная 18px `#eceff2`, прочие 8px `rgba(255,255,255,0.4)`). Выбор вида общий для обоих режимов; при открытии подставляется вид, выбранный на карточке в этот момент.
5. Кнопка «Отправить»: ширина min(80vw, 340px), высота 48, радиус 24, фон цветом темы, текст `#0a0a0b` 15px 600.
6. Тап «Отправить» → рендер PNG (см. «Рендер») → `navigator.share({ files: [file] })`. Системный лист даёт «Сохранить в фото» и мессенджеры - свой UI листа не делать.

## Режим «Карточка»
Живая копия карточки (ширина min(80vw, 340px), радиус 22, рамка `#2a2d31`): фото-слой + скрим, шапка (эмблема, название, процент), середина 132px по выбранному виду, внизу подпись + полоса прогресса.
Четыре вида (0-3): фото-визитка / число дня + строка тренда / график за сутки / столбики 7д. Составы видов - как на главном экране (handoff-README, «Карточка аналитики»). Отличия от карточки экрана:
- текст всегда белый с фиксированной тенью `0 1px 3px rgba(0,0,0,0.7)` (ползунки карточки на предпросмотр не влияют);
- у строки тренда пятно-подложка с фиксированной плотностью: absolute-слой, inset −6px −11px, радиус 999px, blur 8px, фон `rgba(10,10,11,0.42)`;
- переключателя 7д/30д на виде столбиков нет - всегда 7д;
- нижняя строка: на виде 0 - «500 из 2500 мл», на остальных - «последняя запись …».

## Режим «Кадр 9:16»
«Сторис»-открытка. Вся компоновка в процентах и vh - кадр обязан растягиваться пропорционально на любом разрешении, пиксельных координат не допускается.
- Фон: фото темы во весь кадр (object-fit cover); без фото - `#0d0e10`. Поверх виньетка: `linear-gradient(180deg, rgba(10,10,11,0.4) 0%, rgba(10,10,11,0.12) 38%, rgba(10,10,11,0.62) 100%)`.
- Блок числа: left 4%, top 66% (при видах 2/3 - top 58%), выравнивание влево, переход top .3s ease. Состав: число (min(6vh,44px), гротеск --f-geo, 500, `#ffffff`) + «из …» (min(2vh,14px), `rgba(255,255,255,0.85)`); при виде 1 - строка тренда с пятном-подложкой (как выше); дата «7 сентября, понедельник» (min(1.8vh,13px), `rgba(255,255,255,0.72)`).
- Виды 2/3: график за сутки / столбики 7д - left 4%, right 4%, top 76%, `filter: drop-shadow(0 1px 3px rgba(0,0,0,0.7))`; подписи осей/дней `rgba(255,255,255,0.7)`.
- Кольца темы на кадре НЕТ (решение 7.09.2026).
- Подпись внизу: «STANU · beta version» - по центру, bottom 4.5%, min(1.7vh,12px), letter-spacing 0.14em, гротеск --f-geo, `rgba(255,255,255,0.75)`, тень как у текста. Ровно эта строка, с middle dot.
- Тексты кадра с тенью `0 1px 3px rgba(0,0,0,0.7)` (у числа дополнительно `0 2px 14px rgba(0,0,0,0.5)`).

## Рендер и отправка
- PNG рисуется в `<canvas>`: кадр 1080x1920, карточка - ширина 1080, высота по виду. Фото брать из механизма хранения фото темы (не из image-slot прототипа). Данные (значение, цель, процент, тренд, точки графика, столбики) - из модуля темы через тот же контракт, что у карточек главного экрана; UI ничего не считает сам.
- `canvas.toBlob('image/png')` → `new File([blob], 'stanu-<тема>-<дата>.png', {type:'image/png'})` → `navigator.share({files, title})`, предварительно `navigator.canShare({files})`.
- Фолбэки: нет share с files → `navigator.share({url/text})` не использовать, вместо этого скачивание PNG через временную ссылку `<a download>`; нет share вообще → то же скачивание. Кнопка одна и та же, поведение выбирается тихо.
- Отмена системного листа - не ошибка, оверлей остаётся открытым.

## Файлы
- `src/ui/share.js` - оверлей, предпросмотр, переключение режимов/видов.
- `src/ui/share-render.js` - отрисовка PNG в canvas (карточка и кадр).
- Пункт меню - в `src/ui/menu.js`. Стили - в `assets/css/card.css` или новый `assets/css/share.css`, токены из tokens.css.

## Приёмка
1. Меню ⋯ → «Поделиться» открывает оверлей, ⋯-меню закрыто; ✕ закрывает оверлей.
2. Оба режима работают, 4 вида листаются таблетками, стартовый вид = вид карточки.
3. Кадр 9:16 на разных высотах экрана сохраняет пропорции (проверить 568-932pt).
4. «Отправить» на телефоне открывает системный лист с картинкой; картинка попиксельно соответствует предпросмотру; на десктопе без share скачивается PNG.
5. Тексты читаемы на любом фото (тени и пятно тренда на месте); спад тренда серый, не красный.
6. Никаких обращений ui в store напрямую; `node src/core/check.js` (или принятый в репо чек) проходит.
