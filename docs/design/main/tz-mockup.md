## Чего в этом пакете нет
«Уезжающая карточка в "Сегодня"» и «цель с золотой лентой» - это экран «Сегодня» (пакет design_handoff_today_screen, другой проект). Сюда не входят; скриншоты запрашивайте из той сессии.

## Правила приёмки по скриншотам
1. Пиксельные значения не измерять по PNG (масштаб превью) - размеры брать из README; скриншоты фиксируют композицию, слои и состояния.
2. Обязательные инварианты: зазор кольцо-подложка у кружков; тренд при спаде серый, не красный; на фото-виде нет «последней записи»; пятно-подложка есть только у строки тренда; меню ⋯ не обрезается картой.
3. Кадр 9:16 при любой высоте экрана держит пропорции (композиция в %/vh).
