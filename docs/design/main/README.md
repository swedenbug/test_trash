# Handoff: главный экран

## Обзор
Главный экран личного приложения дисциплины (репозиторий swedenbug/test_trash): ряд кружков тем сверху, ниже лента карточек-аналитики с листающимися видами и настраиваемым фото-фоном. Роль рядом с экраном «Сегодня»: «Сегодня» - действия, главный - обзор и аналитика; кружки дают быстрые отметки и здесь. Утверждён в дизайн-сессии 7 сентября 2026.

## О файлах дизайна
`Главный.dc.html` - дизайн-референс на HTML (открывается в браузере, рядом нужны `image-slot.js` и `assets/water-bg.jpg`). Задача - воспроизвести в окружении репозитория: статические HTML/CSS/JS без сборщика и внешних зависимостей, слои core/modules/ui по docs/contracts.md. `image-slot.js` - только механика прототипа для перетаскивания фото; в продукте фото темы хранится своим механизмом.

## Точность
**Hi-fi.** Токены = assets/css/tokens.css. Рамки брифа: колонка 440px, тёмная тема, системные шрифты, касание от 44px, дефис вместо тире, не больше одного тревожного сигнала на экране.

## Структура экрана
1. **Шапка** - sticky (top:0, z-index:40, rgba(10,10,11,0.92) + blur 12px): дата «7 сентября, понедельник» (14px #8c949c, формат: число месяц, день недели), справа меню 44x44 (две линии 20x2 #eceff2).
2. **Ряд кружков** - горизонтальная прокрутка без скроллбара, элементы 76px, gap 16px, нижняя волосяная граница rgba(255,255,255,0.055).
3. **Лента карточек** - gap 16px, padding 16px.
4. **Нижние переходы** - в конце потока (не fixed), верхняя волосяная линия, safe-area снизу; активна «Главная» (#eceff2), остальные #8c949c opacity .55; кнопки 44x52.

## Кружок темы (svg viewBox 0 0 100 100, размер 68px)
- **Кольцо срочности** r=46, толщина 4: спокойно #303c4a; мягко linear-gradient(0.7turn, #4ef29a → #0a8f5c); срочно #ff7a55 → #a30f1e. Под цветным кольцом свечение: та же окружность толщиной 7, цвет #2ecb7f / #e0402e, opacity 0.5, blur 3.5.
- **Подложка** r=38 #141517; зазор кольцо-подложка обязателен.
- **Знак темы**: масштаб 0.59 от кружка; контур цветом темы (stroke 3, opacity 0.4) + заливка снизу вверх по прогрессу дня (rect в clipPath знака; y = 92 − fill·84, переход y .45s ease).
- **Неподключённая тема**: буква (32px, гротеск --f-geo, #5b6268), кольцо #22262b, подпись #5b6268.
- **Подпись** 12px #8c949c под кружком.
- **Поведение**: тап - быстрое значение (заливка плавно растёт, на 1.6с поверх знака проступает процент: диск #0a0a0b opacity .74 + число mono 24px 600). Полные жесты продукта: удержание 1с - второе значение, удержание 3с - экран темы с гашением набранного кольца (src/ui/gestures.js, circle.js).
- Демо: Вода (мягко, 20%), Отжимания (спокойно, 40%), Чтение (срочно, 40%), Кофе (66%), Настроение (0), Питание «П» и Спорт «С» - выключены.

## Карточка аналитики (вода, чтение)
Контейнер: 300px высоты, радиус 22, рамка #2a2d31, фон #141517, overflow hidden, box-sizing border-box везде.

**Слои фона**: фото (object-fit cover; у чтения - зона перетаскивания фото) → скрим → контент. Все параметры фона живут в меню ⋯ (см. ниже).

**Шапка карточки**: эмблема темы 18px в её цвете; название 14px; подпись 12px (скрыта на фото-виде); справа процент (гротеск 20px); кнопка ⋯ 32px (фон rgba(28,30,33,0.65), на фото-виде прозрачный).

**Четыре вида, листаются** перетаскиванием мышью/пальцем (порог 48px, transform translateX, transition .3s ease, во время драга none) и тапом по указателям. Указатели - таблетки 4px высотой: активная 18px #eceff2, остальные 8px rgba(255,255,255,0.4), переход .2s.
1. **Фото («визитка»)** - картинка почти чистая; внизу компактно «500 из 2500 мл» (13px) + полоса; без «последней записи».
2. **Число дня** - 46px гротеск + «из 2500 мл», строка тренда: стрелка-треугольник 11px + «-8% к среднему за 7 дней» (база сравнения - среднее за 7 дней; рост #3ce07e, спад #8c949c - никогда не красный). Цвета строки тренда слушаются ползунка «Акцент текста», но по собственной шкале - оттенки своего же цвета от тёмного к светлому (двухсегментная интерполяция: k 0→0.7 тёмный→базовый, k 0.7→1 базовый→светлый; при дефолте 70 - ровно базовый цвет). Спад (серый): rgb(38,41,45) → #8c949c → rgb(217,221,225). Рост (зелёный): rgb(20,90,52) → #3ce07e → rgb(150,242,186). Семантика оттенка сохраняется на всей шкале.
3. **График за сутки** - polyline кумулятива цветом темы (stroke 2.5), пунктирная линия нормы, подписи 6/12/18/24 (mono 10px #5b6268).
4. **Столбики + переключатель 7д/30д** - сегменты 26px高 (активный: рамка #e6eaee, текст #eceff2); столбики цветом темы (последний opacity 1, прочие 0.45); подписи дней «п в с ч п с в» - ОБЫЧНЫМ HTML-рядом под svg (не svg-text), mono 9px.

**Низ карточки**: полоса прогресса 4px цветом темы на rgba(255,255,255,0.12) + «последняя запись 2 ч назад» (12px; скрыта на фото-виде).

**Пятно-подложка строки тренда** (решение 7.09.2026; только у тренда - распространение на весь текст попробовали и откатили): мягкое размытое тёмное пятно без границ за строкой: absolute-слой, inset −6px −11px, radius 999px, blur 8px, фон rgba(10,10,11, 0.6k), где k = «Тень текста»/100; k≤0.02 → прозрачно; переход background .35s ease. «Прозрачность текста» гасит пятно вместе с текстом (лежит внутри того же opacity-контейнера). На плоских картах неподключённых тем пятна нет.

## Меню ⋯ карточки - четыре ползунка (0-100, с числом в подписи) + «Поделиться»
Панель: absolute, top 52 right 12, min-width 190, фон rgba(28,30,33,0.97), рамка #2a2d31, радиус 12, тень. Ползунки accent-color в цвете темы.
1. **Приглушение фото**: строго непрерывное, без порогов и переломов. 0 - затемнения нет совсем (фото opacity 1, скрим alpha 0). Растут вместе: opacity фото 1 → 0.2; filter grayscale(k) brightness(1−0.3k); скрим - на фото-виде виньетка (сверху 0.5k, середина 0.1k, снизу 0.7k), на остальных видах ровный rgba(10,10,11, 0.55k). Переходы .35-.45s ease.
2. **Акцент текста**: только цвет, интерполяция по k. Основной текст (название, крупное число, мини-строка): rgb(38,41,45) → #ffffff. Второстепенный (подпись, «из 2500 мл», нижняя строка, процент): rgb(28,30,33) → rgb(217,221,225) (на ~12% глуше белого).
3. **Тень текста**: 0 - нет; 50 - мягкая сероватая; 100 - плотная с широким ореолом. Формула: `0 1px (2+2k)px rgba(0,0,0,0.95k), 0 2px (6+14k)px rgba(0,0,0,0.7k)`; k≤0.02 → none. Применяется ко всем надписям на фото.
4. **Прозрачность текста**: opacity всего текста карточки (шапка, вид «число», мини-строка, нижняя строка), полосы и графики не трогает.
Дефолты: приглушение 0, акцент 70, тень 70, прозрачность 100. Значения - настройки карточки, хранить per-тема.

Пятый пункт меню - **«Поделиться»** (иконка share + подпись, отделён волосяной линией). Есть у всех подключённых тем.

## Шеринг (решение сессии 7.09.2026)
Тап «Поделиться» → полноэкранный оверлей предпросмотра (fixed, rgba(10,10,11,0.88) + blur 14): заголовок + ✕ (44px), сегменты «Карточка / Кадр 9:16» (по умолчанию кадр), предпросмотр по центру, кнопка «Отправить» (48px, radius 24, фон цветом темы, текст #0a0a0b).
- **Карточка** - живой предпросмотр с четырьмя видами (фото / число+тренд / график / столбики 7д): под карточкой таблетки-указатели, вид листается тапом; при открытии выбран тот вид, который был на карточке. Отправляется выбранный вид.
- **Кадр 9:16** - «сторис»: фото темы во весь кадр (без фото - тёмный #0d0e10) + виньетка-скрим; те же четыре вида, что у карточки (таблетки под кадром, общий выбор с режимом «Карточка»): 0 - число+дата; 1 - + строка тренда с пятном-подложкой; 2/3 - график/столбики внизу (left/right 4%, top 76%, drop-shadow), блок числа поднимается на top 58% (иначе 66%). Блок числа - слева (left 4%), проценты, не px; внизу (4.5% от низа) подпись «STANU · beta version» (letter-spacing 0.14em, гротеск --f-geo, rgba(255,255,255,0.75)). Кольца на кадре нет (убрано правкой 7.09.2026). Размеры текста в vh - кадр растягивается пропорционально.
- «Отправить» → в продукте Web Share API (navigator.share с PNG из canvas - системный лист «сохранить в фото / мессенджеры»); в прототипе - мок iOS-листа (Сохранить, Telegram, WhatsApp, Ещё + Отмена).

## Карточка неподключённой темы (Питание, Спорт)
Плоская: эмблема-буква #5b6268, название, подпись, «0 из 2100 ккал» (28px гротеск), серая пустая полоса (#303c4a), «тема ещё не подключена». Без видов и ⋯.

## Отложено (заметки будущих сессий)
- Стиль-образец Apple Fitness: неон значков дозированно, цифры в цвете темы, периоды 7д/30д/90д, светящиеся пустые состояния. Обсуждено, не применять без отдельного решения.
- Выбор акцентного цвета пользователем - в меню приложения (бриф: 8 цветов тем).
- Тап по кружку в прототипе не двигает цифры карточек; в продукте оба питаются одним store.
