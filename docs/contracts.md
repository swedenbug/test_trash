# Контракты оболочки и модулей

Стадия: **Концепт**. Волна 1.

Оболочка не знает, что такое вода, подход или учебная сессия. Она умеет три вещи: выстроить кружки по срочности, собрать общую ленту записей и предложить отмену. Всё это работает, пока модуль отвечает контракту.

Правило: **новый модуль не дописывает оболочку.** Если для спорта пришлось править ленту — контракт составлен неверно.

---

## Контракт 1. Срочность

Питает ряд кружков в стилистике историй.

```js
module.getUrgency(now) → {
  level:   'done' | 'soft' | 'hard',
  urgency: 0…1,      // вес для сортировки внутри уровня
  since:   минут с последнего действия,
  summary: '1250 / 2500 мл'
}
```

| Уровень | Кольцо | Смысл |
|---------|--------|-------|
| `done` | Серый, приглушённый | Сделано недавно, внимания не требует |
| `soft` | Зелёный | Пора заняться |
| `hard` | Красный | Затянулось |

**Порядок в ряду:** `hard`, затем `soft`, в конце `done`. Внутри уровня — по убыванию `urgency`.

**Уровень не хранится в базе.** Он вычисляется на лету из последней записи. Хранимое состояние расходится с реальностью — приложение может быть закрыто часами.

**Для воды:** до 72 минут — `done`, от 72 до 180 — `soft`, дальше — `hard`. При выполненной дневной норме потолок — `soft`. Ночь порогов не знает.

## Контракт 2. Лента записей

Питает экран «Недавние записи» — общую ленту по всем модулям.

```js
module.getRecent(since) → [{
  id, moduleId, at,
  title: '250 мл',
  detail: 'тап',        // необязательно
}]

module.removeRecord(id) → Promise
```

**Как собирается:** оболочка опрашивает все модули, склеивает результаты, сортирует по времени по убыванию, применяет фильтр.

| Свойство | Решение |
|----------|---------|
| Окно показа | 24 часа |
| Фильтр | По модулю, переключателем сверху |
| Удаление | Крестик справа в строке, без диалога подтверждения |
| После удаления | Появляется таблетка отмены |

**24 часа — это окно показа, а не срок хранения.** Записи живут бессрочно. Полная история модуля открывается на его собственном экране, лента показывает только свежее.

## Контракт 3. Отмена

Сервис в `ui`. Модуль сообщает о совершённом действии и больше ни о чём не заботится — таймер, кольцо, стопка и исчезновение не его дело.

```js
undo.push({
  label:  'Отменить 250 мл',
  onUndo: () => store.remove('water_intake', id)
})
```

### Как ведёт себя стопка

1. Действие кладётся на вершину стопки. Таблетка показывает вершину и запускает отсчёт **7 секунд**.
2. Новое действие ложится сверху. Таблетка переключается на него, отсчёт начинается заново. Предыдущие остаются в стопке.
3. Нажатие «Отменить» откатывает вершину и снимает её. Таблетка показывает следующую запись — **с новым отсчётом в 7 секунд от момента появления**.
4. Отсчёт истёк — закрывается **вся стопка целиком**, не только вершина.
5. Стопка опустела — таблетка исчезает.

Иначе говоря, стопка жива, пока между действиями проходит меньше семи секунд. Пауза длиннее — и всё сделанное считается принятым.

### Внешний вид

- Таблетка внизу экрана, над безопасной зоной iPhone, чтобы не попадать под полосу жестов.
- Слева — что именно будет отменено. Не «отменить», а «отменить 250 мл»: при стопке из трёх записей нужно понимать, какая уйдёт.
- Справа внутри таблетки — кольцо, отсчитывающее семь секунд.

### Подпись отмены

Слово «Отменить» — постоянная часть таблетки. Переменная часть — только величина, и она ограничена:

- **Не длиннее 24 символов.** Не влезло — обрезается по последнему целому слову.
- **Величина, а не действие:** «250 мл», «Жим ×4», «45 мин». Не «Отменить добавление подхода в упражнении жим лёжа».
- **Модуль отдаёт подпись сам** и отвечает за её краткость. Оболочка длину не наращивает.
- Не укладывается ни во что — отдаёт эмблему и число.

Ограничение намеренно жёсткое. У воды выбор из двух значений, но у спорта и обучения подпись способна разрастись до строки, которую не прочитать за семь секунд.

### Правила

- **Отмена — то же мягкое удаление.** Запись помечается удалённой, из списков исчезает. Отдельного механизма для «свежих, ещё не ушедших» записей нет: исключения из правила удаления порождают расхождения между устройствами.
- **Стопка живёт только в памяти.** Закрыл приложение — отменять нечего. Записи при этом на месте, их можно удалить из ленты.

## Меню оболочки

Кнопка из трёх полос справа сверху. Содержимое на текущий момент:

| Пункт | Что делает |
|-------|-----------|
| Недавние записи | Общая лента за 24 часа с фильтром по модулям |
| Настройки | Нормы, пороги, границы суток |
| Экспорт данных | Выгрузка всего в JSON |

Список растёт по мере появления модулей. Сами модули в меню не попадают — они живут в ряду кружков.

---

## Принято по умолчанию

1. Крестик в ленте удаляет сразу, без диалога. Подтверждение на каждое удаление — два касания вместо одного и раздражение на третьей записи. Страховкой служит таблетка отмены.
2. Полная история модуля живёт на экране самого модуля. Лента ограничена сутками намеренно: это инструмент исправления ошибок, а не просмотра прогресса.
3. Отмена не восстанавливается повторно. Отменил по ошибке — вноси заново, действие занимает одно касание.
