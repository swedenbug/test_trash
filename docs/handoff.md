# Точка передачи

Документ для переезда в новый чат. Он не пересказывает репозиторий, а объясняет то,
чего в файлах нет: где мы находимся, как устроена работа, обо что уже спотыкались
и что решать дальше.

**Что читать и в каком порядке:**

1. Этот файл целиком.
2. `CLAUDE.md` - правила общения и работы. Они соблюдаются буквально.
3. `docs/files.md` - карта репозитория и правило слоёв.
4. `docs/decisions.md` - журнал решений. Длинный; читать по заголовкам, вглубь - по надобности.
5. Дальше по мере надобности: `data-model.md`, `contracts.md`, `theme-engine.md`,
   `postgres-route.md`, `design/main/README.md`, `design/today/README.md`.

## 1. Что за проект

**Личное дело, которое человек ведёт сам с собой.** Не трекер привычек. Трекер отвечает
на вопрос «сколько», личное дело - «держу ли я слово». Планировщик, тренер и журнал
дисциплины в одном.

**Пользователь один - владелец.** Ему 16-30, и у него **есть трудности с самодисциплиной**.
Он не образцовый спортсмен, которому нужен инструмент учёта; он тот, кто много раз начинал
и бросал. Это определяет весь остальной документ.

**Технически:** статический сайт на GitHub Pages, чистые HTML, CSS и JS без сборщика и без
внешних зависимостей. Данные живут в браузере устройства, синхронизация - со своим сервером
Postgres. Основное устройство - iPhone, приложение открывается с ярлыка на главном экране.

## 4. Незыблемое

### Пять правил против машины вины

1. **Всё восстановимо.** Нет показателей, которые нельзя выправить за разумный срок.
2. **Объявленный пропуск - не срыв.** Сказать заранее «сегодня пропускаю» честнее, чем промолчать.
3. **Оценка всегда с трендом**, никогда голым числом.
4. **Не больше одного тревожного сигнала на экране за раз.**
5. **Никаких сравнений ни с кем.** Только с собой прежним.

**Следствие про язык:** ресурс, который тратится, должен быть внешним по отношению
к личности. «Потратил кредит» - расход. «Потратил доверие» - утверждение о том, кто ты есть.

**Серий, которые обнуляются, нет и не будет.** Вместо них бюджет пропусков.

### Технические рамки

- Без сборщика, без внешних библиотек, без внешних шрифтов.
- Колонка 440 пикселей, тёмная тема, зона касания от 44 пикселей.
- Дефис вместо длинного тире во всех текстах интерфейса.
- Имена файлов только латиницей, содержимое русское.
- Местное хранилище не выкидывается никогда. Оно и есть приложение, сервер - копия.

### Правило слоёв

`core` не знает про воду. `modules` не знают друг о друге. `ui` не читает хранилище.
**Проверка: если ради новой темы приходится править `ui` или `core` - контракт неверен.**

## 5. Терминология

| Слово | Значение |
|---|---|
| **Тема** | То, что отслеживается. В коде - модуль |
| **Группа** | Тема-родитель, собирает прогресс из вложенных |

| **Карточка** | Свёрнутый вид темы в ленте главного экрана |
| **Экран темы** | Развёрнутый вид |
| **Заход** | Один обмен сообщениями с одним результатом. Мера объёма работ |

## 7. Грабли, на которые уже наступали

Самая ценная часть документа. Каждая строка стоила заход или больше.

### Передача файлов

- **Пропущенный файл обрывает загрузку целиком.** Один отсутствующий модуль - и страница
  пустая. В консоли будет `404` с именем файла.
- **Устаревший файл опаснее пропавшего.** Он грузится молча и ломается в работе:
  «нет такой функции» в коде, который верен. Отсюда контрольные суммы в `check-files.ps1`.
- **Изменённый файл передаётся всегда**, даже если правка в одну строку.
- **Список сумм пересобирается последним действием захода.** Собранный в середине -
  врёт, и врёт убедительно. Эту ошибку допускали дважды.

### Инструменты

- **Браузер кэширует.** Файл на диске свежий, проверка довольна, в браузере старая версия.
  Отсюда `tools/serve.py` с запретом кэширования вместо `python -m http.server`.
- **Windows PowerShell читает `.ps1` в системной кодировке.** Русский текст превращается
  в набор символов с типографскими кавычками, PowerShell считает их настоящими, строка
  обрывается, разбор падает на случайной скобке. Служебные скрипты - только латиницей.
- **Запись файла идёт через временный файл с переименованием.** Прямая запись при ошибке
  кодировки оставляет исходник пустым.
- **Дописывание больших блоков может оборваться на 64 килобайтах**, посреди символа,
  без ошибки. После дописывания файл перечитывается целиком.

### Браузер и вёрстка

- **Собственное значение `display` перебивает атрибут `hidden`.** Скрытая панель ловила
  касания на весь экран. Общее правило `[hidden] { display: none !important; }`.
- **Таблетка отмены должна быть выше панелей.** Иначе удалил запись в ленте - и отменить
  нечем, кнопка не нажимается.
- **Перерисовка вешается на изменение данных, а не на действие.** Действие приходит откуда
  угодно, данные меняются в одном месте.
- **У дуги SVG радиус не может быть меньше половины хорды.** Меньший браузер молча
  увеличивает, дуги совпадают, фигура исчезает. Выглядит как пустое место, не как ошибка.
- **Межстрочный интервал наследуется в поля ввода** и поднимает текст на пару пикселей.
- **Заливка знака считается по его габаритам, а не по всему полю.** Иначе у капли
  девяносто процентов выглядят как сто.

### Сервер

- **`sshd_config.d/50-cloud-init.conf` переопределяет основной файл.** Правка только
  основного не закрывает вход по паролю, но выглядит успешной. Молчаливый отказ.
- **Смена владельца не меняет режим доступа.** Папка с правами `700` даёт
  `command not found` на существующий файл.
- **`cp env.example .env` создаёт файл, читаемый всей системой.** Там пароль базы.
- **Копия, которую не пробовали восстановить, копией не является.**

### Процесс

- **Ассистент не имеет доступа к репозиторию.** Формулировка «положил в репозиторий»
  однажды привела к тому, что тринадцать снимков числились на месте, а на диске их не было.
  Правильно: «подготовил, передал».
- **Визуальные артефакты без брифа не создаются.** Логотип, иконки, палитра, названия -
  сначала вопрос, потом эскиз, потом отрисовка.
- **К каждому шагу, который что-то закрывает или включает, идёт проверка снаружи:**
  вход по паролю - с клиента, автозапуск - перезагрузкой, копия - разворотом.
- **Документ, объявляющий себя полным описанием, обязан проверяться машиной.**

## 8. Открытые вопросы

1. **Контраст текста на фото.** На снимке `design/main/screenshots/02-main.png` текст
   карточки на светлом фото почти не читается при дефолтных ползунках (акцент 70).
   Предложение: подбирать дефолт по средней яркости фото. Решать в дизайн-чате.
2. **Хранение фото тем.** Один снимок с телефона забивает браузерное хранилище целиком.
   Нужен IndexedDB и сжатие. Это полтора-два захода, и от этого зависит ползунок
   «Приглушение фото» и режим шеринга «Кадр 9:16».
3. **`docs/design/README.md`** - файл есть в репозитории, но не в списке сумм. Разобраться,
   что это, и либо внести в список, либо удалить.
4. **Демо-цвета дизайна.** В хендоффах отжимания зелёные, кофе янтарные - эти цвета
   выведены из палитры тем. Заменить на бирюзовый и песочный при реализации.

## 9. План

| № | Заход | Примечание |
|---|---|---|
| 1 | Сервер: новые таблицы движка тем | Сервер всегда первый, иначе записи теряются молча |
| 2 | Устройство: схема, снос воды | Данные тестовые, миграции нет. Ветка `feat/theme-engine` |
| 4 | Движок как модуль, главный экран на темах | По контрактам из `contracts.md`. Та же ветка |
| 5 | Форма создания темы на живых данных | Макет готов: `states-theme.html` |
| 6 | Оформление главного экрана по хендоффу | `design/main/README.md` |
| 7 | Вкладка «Сегодня» | `design/today/README.md` |
| 8 | Цели и кредит доверия | |
| 9 | Шеринг | `design/main/tz-share.md` |

**Номер 3 пропущен намеренно.** Заход «полный обмен перед чисткой старых таблиц»
отменён вместе с переездом воды: переносить нечего. Остальные номера не сдвинуты -
на них ссылаются `theme-engine.md` и журнал решений, и перенумерация превратила бы
эти ссылки в неправду молча.

**Заходы 2 и 4 идут в ветке `feat/theme-engine`.** После сноса воды приложение
не работает до конца захода 4, а Pages отдаёт `main` - и всё это время на телефоне
должна оставаться рабочая версия. Ветка вливается после приёмки захода 4.

Между 1 и 2 вклинился заход 1.5: устойчивость обмена. Поштучное отбрасывание,
отказ на незнакомое поле, список отвергнутых на устройстве. Без него заход 2
отправил бы всю историю воды одной пачкой, и одна негодная строка остановила бы
обмен насмерть и молча.

### Хвосты, о которых легко забыть

Два из трёх после отмены переезда воды перестали быть хвостами и вошли в заход 2:
делать их отдельно больше не за чем, снос и уборка за ним — одна работа. Третий
остаётся хвостом и всплывёт заходом позже, когда причина уже забудется.

**Убрать воду из `schema.js` — часть захода 2.** `water_intake` и `water_goal`
уходят из `collections` и из `SYNCED`, старые таблицы на сервере удаляются там же.
Месяц страховки не нужен: страховать нечего, данные тестовые. Пока таблицы остаются
в `SYNCED`, они ездят по сети каждый обмен, ничего не содержа.

**24 проверки ядра — тоже заход 2.** `check.js` написан на водных таблицах,
и после сноса часть проверок проверяет несуществующее. Переписать на `theme`
и `entry` нужно в том же заходе: `check.html`, показывающий зелёное на пустом
месте, хуже красного - он снимает вопрос, вместо того чтобы его поставить.

**Экран темы вместо `water-screen.js` — заход 4, и он от этого вырастет.**
Сегодня развёрнутый экран знает про воду: миллилитры, норма, ручной ввод от 1
до 5000. Общий экран должен строиться по виду темы - счётчик, время, шкала,
флажок, заметка. Это не переименование файла, а новый модуль по контракту;
оценка захода 4 увеличивается, и лучше это знать до его начала, чем в середине.

## 10. Как убедиться, что всё живо

```powershell
powershell -ExecutionPolicy Bypass -File tools\check-files.ps1   # 86 файлов, OK
py tools\serve.py
```

Открыть по очереди:

- `/check.html` - должно быть «Ядро исправно: 24 из 24»
- `/app.html` - тап по кружку воды пишет 250 мл, появляется таблетка отмены
- меню → «Сервер» → «Проверить связь» - пропуск принят
- `/states-theme.html`, `/states-today.html`, `/states-looks.html` - макеты открываются

На телефоне: `swedenbug.github.io/test_trash/app.html`, удержание кружка секунду даёт
литр, три секунды открывают экран темы.
